# First benchmark run — 2026-10-11

The loop-closure evidence for Spec 1 Phase 1. Generated by the commands in the
repo-root `TUTORIAL.md` (Track B) with `--seed 20261011`; copyright-audited
(public-domain / open English corpora only). See `summary.md` for the table, the
panel composition, and token totals.

- **Task / scope:** 100 seeded English `retrieve_quote` questions, balanced 25 each
  across Protestant Christian, LDS, Roman Catholic (encyclicals), and Judaism
  (Talmud, English). Question-set digest `ef837474ed7b22ec`.
- **Panel:** 4 models / 2 serving providers — `claude-haiku` (Anthropic direct) +
  `gpt-oss-20b`, `gemma-3-4b`, `llama-3.1-8b` (via OpenRouter). Tokens: 25,220 in /
  134,131 out.

## Reading the scores (important caveat)

The `retrieve_quote` headline is deliberately strict: the whole answer must be the
exact text and **nothing else** (the Phase-6-gated contract). `exact` / `normalized`
/ `token_f1` are reported alongside so the strictness is visible.

A `correct = 0` is **not** one thing — this run mixes two very different behaviours,
and the headline number conflates them:

- **Abstention (honest refusal).** `gpt-oss-20b` answers with an explicit refusal
  ("I'm sorry, but I can't provide that.") for most questions (~58 of 100 verbatim,
  the rest short non-answers); `claude-haiku` abstains on texts it won't reproduce
  "from memory" (e.g. the encyclicals, Talmud).
- **Fabrication (confident but wrong).** `gemma-3-4b` and `llama-3.1-8b` emit
  fluent, plausible scripture-like text that is simply not the requested verse
  (mean `token_f1` 0.13–0.21 — wrong text, not a formatting miss).

For Phase 1's "reject false premises / incorrect text" objective, the
**abstention-vs-fabrication split is the most informative cut** and is the natural
next metric — deferred to the review doc / Spec 2 because the scoring contract is
gated (see `codev/reviews/1-*.md`). Relatedly, `claude-haiku`'s 24% understates its
retrieval: 17 answers reproduce the verse correctly but add a citation prefix and so
lose to the "nothing else" rule (`token_f1` surfaces these; a relaxed
"quote-contained" metric is a Spec-2 refinement).

## Cross-translation (extra reading, same 100 questions)

The headline score is unchanged. `cross_translation.json` / `cross_translation.md`
ask a further question of these answers: when the quote is wrong, is it another
edition, or another tradition's wording of the same citation?

The index already makes that possible. Of the verses present in KJV, ASV, and WEB,
almost all still differ after normalisation, so a real edition can fail the edition
that was asked for. The Protestant KJV and the Latter-day Saint 2013 KJV disagree
on a smaller orthographic set (a space, a hyphen). Elsewhere the same words are a
faithful quotation of two traditions: Book of Mormon verses, mostly Isaiah, match
a KJV verse. Asking for one and receiving the other is not a fabricated verse, and
the headline `correct` bit still marks it 0.

On this run the clear case is Isaiah 4:6. The question asks for the Protestant
KJV ("day time"). `claude-haiku` returns the Latter-day Saint 2013 wording
("daytime") and scores 0. Several ASV and WEB questions are answered with the KJV
instead. See `cross_translation.md` for the rows.

`facct.md` opens with the claim this run can support, what would make that claim fail
(including the missing temperature and the hosts behind gpt-oss), and what the card
will not conclude. `facct.json` / `facct.md` also split every answer into exact, the right verse plus
extra words, another tradition, another edition, a near miss (token overlap at
least 0.7), a refusal, an empty answer, or a fabrication. They also record the
languages that were not sampled, the license and document type of each slice,
and that scholar review is not attached. The headline `correct` bit in
`scores.jsonl` is unchanged.

## Copyright audit scope

The audit ran **origin-only** here: its content layer fingerprints restricted unit
texts only when the held-back restricted payloads are present locally, and none are
in this corpus (the run uses no restricted source). Origin is the enforceable proxy
in a clone / CI, where restricted payloads are never committed.
