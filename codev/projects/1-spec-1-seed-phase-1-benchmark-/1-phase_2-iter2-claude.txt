## Blocking: the `encyclicals` rebuttal premise is false, and the fix papers over the real shape

Fix #2 replaced the colliding `paragraph` field with a positional index. The rebuttal justified discarding the source numbers entirely:

> **50 of 201 files even have duplicate *non-null* paragraph numbers**, so no number-preserving rule is collision-free.

The 50-file count is accurate, but the inference is wrong. I checked *why* those numbers collide — they are not ambiguous source numbering. Each encyclical's `paragraphs` array concatenates **body prose followed by a footnote block whose numbering restarts**:

```
aeterni-patris.json
  idx 36  paragraph 34  "In fine, relying on the divine assistance…"   <- last body para
  idx 37  paragraph  5  "De Trinitate, 14, 1, 3 (PL 42, 1037); quoted by Thomas Aquinas…"
  idx 38  paragraph  6  "Clement of Alexandria, Stromata, 1, 16 (PG 8, 795)…"
```

All 258 duplicate groups are non-adjacent (zero are continuations) — they are body-vs-footnote pairs. Splitting at the numbering restart (`paragraph < running max`) yields **unique body numbers in 201/201 documents**. A number-preserving, collision-free rule therefore does exist; the collisions were an artifact of a shape the converter doesn't model. This is precisely the project's own `lessons-critical.md` rule — derive the format from the real data, not from a summary statistic about it.

Two consequences, both affecting the headline metric:

**1. Ground-truth citations are wrong in 141/201 documents.** The positional index diverges from the true paragraph number wherever unnumbered front matter precedes the body:

```
ad-petri-cathedram.json   (all 148 numbered paragraphs mismatch)
  pos 1 -> paragraph None  "To the Venerable Brethren, the Patriarchs…"
  pos 2 -> paragraph None  "We who have been elevated despite Our unworthiness…"
  pos 3 -> paragraph 2     "For these reflections of Ours…"
```

So `retrieve_quote` for `"Ad Petri Cathedram, para. 3"` carries real paragraph 2's text as ground truth. A model that knows the encyclical correctly is scored **wrong**, and `cite_passage` ground truth is likewise non-canonical. This inflates the measured hallucination rate — the number the FAccT paper reports — and it is the same class of defect as the heading-as-verse bug fixed in #1.

**2. 662 entries (6.1%, across 55 docs) are bibliographic footnotes emitted as `unit_type="paragraph"`.** Asking a model to retrieve *"Clement of Alexandria, Stromata, 1, 16 (PG 8, 795)."* as encyclical prose is not a meaningful benchmark item. (`paragraphCount` is just the array length — it equals `len(paragraphs)` in all 201 files, so it is not a usable discriminator; the numbering restart is.)

A rule consistent with the data: split the footnote block at the restart; cite body paragraphs by their **declared** number (`{title}, para. {n}`) — now unique everywhere; skip footnotes or namespace them (`{title}, n. {k}`); and for the 2881 null-numbered body paragraphs (genuine prose, no citable number) use an explicitly non-canonical marker so Phase 5 `generate` can exclude them from citation-dependent tasks. The existing `_require_unique_citations` post-condition will hold.

The current real-data test (`test_convert_encyclicals_real`) asserts 201 docs / 10925 entries and per-document citation uniqueness — all true, but uniqueness is satisfied by construction under positional indexing, so the test cannot detect either problem. It needs an assertion tying a citation to the source's declared number, and one that no entry is a footnote.
