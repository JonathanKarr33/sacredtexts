### Non-blocking observations

1. **O(n²) in the duplicate-citation error path** (export.py:106): `{c for c in citations if citations.count(c) > 1}` only runs after the O(n) `len != len(set)` trip, but on the 78406-entry Talmud that is ~6×10⁹ string comparisons — a fail-fast path that would take minutes to print its message. A `Counter` would make it O(n). Unreachable on today's data; worth fixing when convenient.
2. **`source_url` is unverified by `roundtrip_ok`.** It is reasonably documented as best-effort for multi-shard merges, but 219 of the 220 real groups are single-shard, where line 111 preserves it exactly — so an assembler that invented a `source_url` would pass. A cheap strengthening: assert the assembled `source_url` is `None` or one of the shards' values.
3. **`assemble` aliases input `Entry` objects** into the output documents (the test at line 118–119 acknowledges this). Mutating an assembled document's entries mutates the shard. No current caller does, but it is a latent foot-gun.
4. **The CLI assembles twice** — `exp.assemble` at cli.py:144 and again inside `roundtrip_ok`. Completed fast enough on 350k entries in my run; noting only in case the corpus grows.
