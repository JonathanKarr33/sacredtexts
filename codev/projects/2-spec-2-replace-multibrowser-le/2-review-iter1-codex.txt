KEY_ISSUES:
- `apps/viewer/vite/runsEndpoint.ts:65-91` canonicalizes only the root, then relies on `lstat` and lexical containment for the requested file. It never calls `realpath` on the target, contrary to the binding spec requirement, and a directory swapped to a symlink between checks can escape `runs/`. Canonicalize the resolved target, verify containment, retain component-level symlink rejection, and add a regression test.
- `apps/viewer/src/components/QuestionList.tsx:78-84` hides the metric grid for missing failures, while the specification requires every failing question to show its per-metric values. Render the metrics as `n/a` for missing results, or reconcile the specification and documentation; currently the component test explicitly codifies behavior that contradicts the spec and review’s AC6 claim.
