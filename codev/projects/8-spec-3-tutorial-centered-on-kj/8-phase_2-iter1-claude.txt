## Blocking issue: `stop_reason` guard covers only `max_tokens`

`providers.py:90` raises on `stop_reason == "max_tokens"`. The installed SDK's `StopReason` literal is:

```
"end_turn", "max_tokens", "stop_sequence", "tool_use", "pause_turn", "refusal", "model_context_window_exceeded"
```

**`pause_turn` is Anthropic's documented stop reason for a long-running turn with a *server-side tool* — i.e. exactly the web-search path this phase adds.** On `pause_turn`, `refusal`, or `model_context_window_exceeded`, the turn is incomplete, and the current code silently accepts whatever text blocks happen to be present:

- partial text present → committed as if it were the model's real answer. It scores 0 on whole-answer equality and is **indistinguishable in `answers.jsonl` from a search-on model that simply got the quote wrong** — which corrupts the one contrast this whole spec exists to display, inside a run that Phase 3 commits to a public repo.
- no text present → falls into the generic `RuntimeError("empty response")` path at line 63, which **retries twice, re-billing the web search each time** — the precise cost failure the `max_tokens` comment at line 87-89 was written to avoid.

I settled this by reading rather than mutating: the only `stop_reason` branch in `_anthropic` is the `max_tokens` equality check, and `complete()`'s `except Exception` wrapper is the sole other path, so there is no second guard anywhere. Test coverage matches — `test_max_tokens_truncation_fails_loud` is the only `stop_reason` test; nothing exercises `pause_turn`.

The fix is one line, consistent with the project's fail-fast rule and the plan's own "validate the response shape and fail loud on mismatch": allowlist the terminal-success reasons and raise `ProviderError` otherwise, e.g.

```python
_OK_STOP = {"end_turn", "stop_sequence", "tool_use"}
if (sr := getattr(resp, "stop_reason", None)) not in _OK_STOP:
    raise ProviderError(f"{model.id}: incomplete turn (stop_reason={sr!r}) — ...")
```

plus a test case asserting `pause_turn` raises. Worth doing **before** Phase 3 spends money and commits evidence, not after.
